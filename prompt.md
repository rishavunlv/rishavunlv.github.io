### The "Big Tech" BI Dashboard Prompt

**Role:** You are a Senior Frontend Engineer and Data Architect at a FAANG company.
**Objective:** Create a single-page, static "Data Intelligence Command Center" using HTML5, CSS3, and Vanilla JavaScript. This project must demonstrate professional-level Business Intelligence (BI) and Data Analytics skills by visualizing complex AI workflows and risk propagation.

**Project Structure & Navigation:**
Create a modern, "Antigravity-inspired" dark-themed UI with a navigation bar containing three interactive tabs:

#### **Tab 1: GraphRAG Risk Propagation Explorer**

* **The Concept:** Showcases mastery of **Neo4j**, **LangGraph**, and **GraphRAG** relationships.
* **UI Elements:** Use a library like **vis.js** or **D3.js** (via CDN) to render a static network graph.
* **Data Insight:** Visualize how a security vulnerability in a "Healthcare" or "Finance" sector asset propagates through a network.
* **Features:** Clicking a node (e.g., "Salesforce Flow") should show its "Context Depth" and its relationship to the **CISO Budget**. Use static JSON to simulate **Vector DB (Pinecone/Chroma)** retrieval of "Risk Documentation."

#### **Tab 2: AIOps & FinOps Observability Dashboard**

* **The Concept:** Showcases **AIOps**, **AWS Free Tier** optimization, and **liteLLM/OpenRouter** orchestration.
* **UI Elements:** Use **Chart.js** to show multiple time-series graphs.
* **Data Insight:** Plot "Token Efficiency" and "Inference Cost" across 10 iterations of **Harness Engineering**.
* **Features:** Show a "Model Switching" log where the system automatically routed a task to local **Ollama** for privacy or **Claude 3.5** for high-reasoning. Include metrics for **n8n** and **Zapier** automation latency.

#### **Tab 3: AI Red Teaming & Security Audit**

* **The Concept:** Showcases **AI Red Teaming**, **Context Engineering**, and **Harness Engineering**.
* **UI Elements:** A "Log Viewer" style interface with status badges (e.g., "Intercepted," "Mitigated").
* **Data Insight:** Display a table of "Prompt Injection" attempts against the **Salesforce Prompt Generator**.
* **Features:** Showcase "Before and After" context engineering snippets. Show how **Harness Engineering** benchmarks prevented data leakage. Mention the use of **MCP (Model Context Protocol)** servers for secure local data handling.

**Technical Specifications:**

1. **Styling:** Use a professional dark theme: Navy background (`#0b0f19`), Teal accents (`#00c6a2`), and Amber warnings (`#f5a623`).
2. **Responsiveness:** Use CSS Grid and Flexbox for a layout that works in **GitHub Codespaces**.
3. **Data Handling:** All data must be hardcoded as static JS objects or JSON to ensure it runs without a backend while simulating complex databases like **Neo4j** and **Pinecone**.
4. **Keywords to include in UI tooltips/labels:** Antigravity, LangChain, LangGraph, RAG, GraphRAG, AIOps, Red Teaming, Harness Engineering, Context Engineering, and AWS.

**Final Deliverable:** Provide the complete code for `dashboard.html`, `dashboard-styles.css`, and `dashboard-logic.js`. Ensure the code is modular, heavily commented with "Business Intelligence" explanations, and ready to be added to the current project directory.

### Why this prompt works:

* **Static but Deep:** It proves you can handle complex data structures (GraphRAG, AIOps logs) without needing a live server, which is perfect for a fast-loading portfolio.
* **Professional Storytelling:** It frames your tools (n8n, Zapier, LiteLLM) as parts of a **Business Intelligence** strategy, not just "cool tech."
* **Hiring Alignment:** By focusing on **Red Teaming** and **FinOps (AIOps)**, you are directly addressing the top concerns of teams at Google and Meta.
